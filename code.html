信標程式碼

模擬器韌體燒錄裝置設定系統簡介

地點信標只做一件事：用藍牙低功耗固定廣播一個 iBeacon（或固定名稱），讓手錶判斷「在不在附近」。不收資料、不連線。不想自己編譯的話，直接到 韌體燒錄 選角色燒錄即可。

下載 beacon_tx.ino

用 Arduino IDE 自己編譯

項目LILYGO T-QT Pro（有狀態螢幕）ESP32-C3 小板（無螢幕）
開發板套件esp32 by Espressif（3.x 版）
需要的函式庫NimBLE-Arduino（2.x）、LovyanGFXNimBLE-Arduino（2.x）
板子選擇ESP32S3 Dev ModuleESP32C3 Dev Module
重要設定Flash Size 4MB；Partition Scheme「Huge APP」（中文字型較大）；USB CDC On Boot「Enabled」USB CDC On Boot「Enabled」；程式開頭把 HAS_TQT_SCREEN 改成 0
名稱與編號燒完後到 裝置設定 頁用 USB 修改，不必改程式；也可以在序列埠監看視窗輸入 set 2 廚房洗手台（編號 名稱）、info。同一個家裡每顆信標的編號要不同。

UUID 用這個專案自己的固定值；要和別的專案區分，可自行換一組隨機 UUID（手錶登錄時會一併記下）。螢幕腳位與初始化序列適用 T-QT Pro（GC9107，0.85 吋）。
