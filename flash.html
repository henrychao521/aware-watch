不用安裝任何軟體：用電腦版 Chrome 或 Edge 開這一頁，選好要燒的裝置，接上 USB 就能燒錄。

2. 連接並燒錄

  1. 用 USB 資料線（不是純充電線）接上板子。
  2. 按「連接並燒錄」，在清單選要燒的那塊板子，按「連線」。同時接著手錶和信標時特別注意：信標（T-QT Pro）通常顯示 USB JTAG/serial debug unit，手錶顯示 USB Single Serial；選錯時頁面會依記憶體容量擋下，不會燒進去。
  3. 等進度條跑完，看到「燒錄完成」板子會自動重開機。

手錶平常更新不要勾「先清除全部資料」：勾了會一併清掉錶上的紀錄、教學範本與已登錄的信標。

狀況怎麼處理


清單裡沒有板子、或燒到一半斷線讓板子進入燒錄模式：按住 BOOT 鍵，再按一下 RESET（或 RST），放開 BOOT；若板子沒有 RESET 鍵，就按住 BOOT 拔掉 USB 再插回去，插好後再放開。然後重按「連接並燒錄」。燒完拔插一次 USB 或按 RESET 重開機。


連線後說晶片不對手錶與 T-QT Pro 信標是 ESP32-S3；無螢幕信標是 ESP32-C3。請回第 1 步選對裝置。


一直失敗換一條確定能傳資料的線；關掉 Arduino IDE 的序列埠監看視窗（它會占住連接埠）；USB 集線器有問題就改插電腦本體。





燒錄後


手錶：接上電腦時可用序列埠對時；操作方式可先在 模擬器 熟悉。

信標：T-QT Pro 版開機會顯示角色與綠燈「廣播中」，30 秒後自動關背光，按任一鍵再亮；無螢幕的 C3 版只能用手錶「地點」頁掃描確認。放好後到手錶「地點」頁登錄。




燒錄工具使用 esptool-js（Espressif，Apache-2.0）。研究原型，非醫療器材。
